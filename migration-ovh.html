Checklist de migration OVH

Procédure recommandée pour passer le site en production sur hébergement OVH sans interruption majeure.

Avant migration

  • Créer une sauvegarde complète: fichiers + base de données.
  • Baisser le TTL DNS (ex: 300s) pour accélérer le switch.
  • Vérifier que le domaine pointe vers l'hébergement cible (A/AAAA/CNAME selon architecture).
  • Préparer les accès: FTP/SFTP, base MySQL, panel OVH, DNS.

Migration technique

  1. Copier les fichiers WordPress sur l'hébergement OVH.
  2. Importer la base de données.
  3. Adapter wp-config.php (DB_NAME, DB_USER, DB_PASSWORD, DB_HOST).
  4. Lancer un remplacement d'URL (ancien domaine → nouveau domaine) si nécessaire.
  5. Vérifier les permissions fichiers/dossiers.

Après bascule DNS

  • Activer HTTPS (certificat SSL Let's Encrypt ou OVH).
  • Vérifier redirection HTTP → HTTPS.
  • Tester toutes les pages clés + formulaires simulateur et RDV.
  • Vérifier envoi email (admin + utilisateur).
  • Purger les caches (plugin/CDN/navigateur).

Supervision post go-live

  • Surveiller erreurs PHP et logs serveur.
  • Surveiller demandes de contact/RDV reçues.
  • Contrôler performances (temps de chargement page d'accueil + contact).
