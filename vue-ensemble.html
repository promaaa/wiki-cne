Architecture fonctionnelle et technique

Le site repose sur WordPress avec un thème sur-mesure et un plugin métier CNE.

Composants principaux

ComposantRôle
Thème cne-premium-themeDesign, templates de pages, header/footer, scripts front.
Plugin cne-unified-pluginCPT, shortcodes métier, formulaires, RDV, Google Calendar.
WordPress Core + plugins tiersCMS, sécurité, éditeur, extensions sociales/SEO/etc.

Données métier gérées

  • Études (CPT cne-etudes) avec pôle et témoignage client.
  • Équipe (CPT equipe) avec URL LinkedIn et pôle.
  • Partenaires (CPT cne-partner).
  • Demandes de contact (table DB wp_cne_contacts).
  • Demandes de RDV (table DB wp_cne_appointments + éventuel ID Google Event).

Flux fonctionnels clés

  1. Un prospect remplit le simulateur → demande stockée + email admin.
  2. Un prospect prend RDV → vérification disponibilité → création agenda + emails de confirmation.
  3. Les contenus études/équipe/partenaires sont rendus via shortcodes et templates.
Le site peut fonctionner même sans Google Calendar : un fallback email/ICS est prévu pour les rendez-vous.

Points sensibles à surveiller

  • Validité des clés Google Calendar (service account + partage calendrier).
  • Délivrabilité email (SPF/DKIM/SMTP).
  • Mises à jour WordPress/plugins (prévoir préproduction).
  • Sauvegardes fichiers + base de données.
