Configuration des Emails

Le site CNE envoie automatiquement des emails de confirmation aux clients lors d'une demande de devis ou d'une prise de rendez-vous. Pour que ces emails fonctionnent correctement, une configuration SMTP est nécessaire.

Important : Par défaut, WordPress utilise la fonction PHP mail() qui ne fonctionne généralement pas sur les hébergements (elle est souvent désactivée pour éviter le spam). Vous devez installer un plugin SMTP pour recevoir les emails.

Emails envoyés automatiquement

  • Demande de devis (simulateur) : Email de confirmation envoyé au client avec le résumé de sa demande
  • Prise de rendez-vous : Email de confirmation avec invitation calendrier (.ics)
  • Notification admin : Email envoyé à l'administrateur pour chaque nouvelle demande

Solution recommandée : Installer WP Mail SMTP

1. Installer le plugin

  1. Aller dans Extensions → Ajouter
  2. Rechercher "WP Mail SMTP"
  3. Installer et activer le plugin gratuit

2. Configurer le plugin

  1. Aller dans WP Mail SMTP → Réglages
  2. Choisir un service mail parmi :
    • Gmail / Google Workspace - Connexion OAuth (recommandé)
    • SendGrid - API ou SMTP
    • Mailgun - API
    • SMTP.com - SMTP simple
    • Autre SMTP - Configuration manuelle (serveur, port, identifiants)
  3. Suivre l'assistant de configuration du plugin
  4. Activer l'option "Email deliverability" pour fiables

3. Tester l'envoi

  1. Aller dans WP Mail SMTP → Tests d'email
  2. Entrer une adresse email valide
  3. Cliquer sur "Envoyer un email de test"
  4. Vérifier la boîte de réception (et les spams)

Configuration avec Gmail / Google Workspace

Méthode recommandée pour CNE (compte Gmail ou Google Workspace classique) :

  1. Dans WP Mail SMTP, sélectionner "Google / Gmail"
  2. Cliquer sur "CONNEXION AVEC GOOGLE"
  3. Autoriser l'application à envoyer des emails
  4. Configurer l'expéditeur : noreply@ VOTRE-DOMAINE.com
Bon à savoir : Si vous utilisez un nom de domaine personnalisé (ex: cne-nantes.fr), il est recommandé d'utiliser le même domaine pour l'adresse email d'expéditeur pour éviter que les emails soient marqués comme spam.

Dépannage

Problème Solution
Emails non reçus Vérifier les spams, tester avec WP Mail SMTP, vérifier les logs
Erreur d'authentification Google Regénérer le Client ID OAuth dans Google Cloud Console
Emails goes to spam Utiliser un domaine d'expéditeur cohérent (ex: @cne-nantes.fr)
