Guide de prise en main du site CNE

Objectif : ce guide vous permet de maintenir les contenus, les formulaires et les intégrations (Google Agenda / LinkedIn / Slack) sans toucher au code.

Pour commencer, consultez le Guide de prise en main qui détaille toutes les étapes de configuration.

Parcours recommandé

  1. Lire Vue d'ensemble pour comprendre l'architecture.
  2. Configurer les options générales dans Accueil.
  3. Configurer les contenus (études, équipe, partenaires) via CPT, Équipe et Articles (Substack).
  4. Configurer les formulaires et prises de RDV via Simulateur & RDV.
  5. Connecter les notifications Slack dans Slack.
  6. Activer l'agenda dans Google Agenda.
  7. Vérifier le flux social dans LinkedIn.
  8. Suivre la checklist de go-live dans Migration OVH.
