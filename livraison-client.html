Livraison Client — Centrale Nantes Études

Ce document est la page de référence à transmettre au client final pour la prise en main du site.

1) Contenu livré

  • Site WordPress complet (thème + plugin + contenus).
  • Configuration serveur (conf/) pour environnement local/technique.
  • Wiki de maintenance et d'exploitation.

2) Configuration client obligatoire

  1. Vérifier les réglages généraux WordPress (site, fuseau, permaliens).
  2. Renseigner contact global (email, téléphone, adresse, lien LinkedIn).
  3. Configurer Google Agenda dans Réglages → CNE Google Agenda.
  4. Configurer Google Analytics 4 dans Apparence → Personnaliser → CNE - Analytics (voir §3bis).
  5. Valider l'envoi d'emails (idéalement via SMTP transactionnel).
  6. Configurer les notifications Slack dans Réglages → CNE Slack.
  7. Tester les formulaires Simulateur et RDV de bout en bout.

3bis) Configuration Google Analytics 4

Pour activer le suivi Analytics, le client doit :

  1. Créer un compte GA4 sur analytics.google.com
  2. Récupérer le Measurement ID (format : G-XXXXXXXXXX) dans Admin → Flux de données → Web
  3. Configurer dans WordPress :
    • Aller dans Apparence → Personnaliser
    • Cliquer sur "CNE - Analytics" dans le menu de gauche
    • Coller le Measurement ID dans le champ prévu
    • Cliquer sur "Publier"
Astuce : Laissez le champ vide si vous ne souhaitez pas utiliser Google Analytics. Le code de suivi ne sera pas inséré.

3) Checklist recette avant mise en production

  • Page Accueil / Prestations / Contact / Actualités fonctionnelles.
  • Aucune erreur critique PHP ou JavaScript.
  • Flux LinkedIn affiché correctement.
  • Prise de RDV crée un événement Google et envoie une invitation par email (fichier ICS).
  • Footer, navigation desktop/mobile et liens légaux valides.

4) Procédure de mise en production

Suivre strictement: Migration OVH.

Sécurité : ne jamais transmettre les clés privées (Google JSON, SMTP, mots de passe) par email non sécurisé. Utiliser un coffre-fort partagé.
