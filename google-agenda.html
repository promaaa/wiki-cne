Intégration Google Agenda (RDV)

Le plugin CNE intègre un menu d'administration dédié pour connecter les prises de RDV à Google Calendar.

Emplacement de configuration

WordPress Admin → Réglages → CNE Google Agenda

Données à renseigner

Champ Description
ID du calendrier Google Ex: xxxxx@group.calendar.google.com
Service Account JSON Contenu JSON complet du compte de service Google Cloud.

Procédure complète

  1. Créer un projet Google Cloud.
  2. Activer l'API Google Calendar.
  3. Créer un compte de service.
  4. Générer une clé JSON et copier son contenu.
  5. Partager le calendrier Google cible avec l'email du compte de service (droits "modifier les événements").
  6. Coller JSON + Calendar ID dans WordPress et enregistrer.
  7. Vérifier l'état de connexion affiché en vert.
