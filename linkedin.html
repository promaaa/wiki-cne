Configuration LinkedIn

Le site intègre LinkedIn à plusieurs niveaux pour renforcer la présence sociale de CNE.

1) Liens LinkedIn individuels (Équipe)

Chaque membre de l'équipe peut avoir son propre lien LinkedIn affiché sur sa photo :

  1. Allez dans le menu Équipe dans la barre latérale de WordPress.
  2. Modifiez le profil du membre souhaité.
  3. Dans la section des champs personnalisés CNE, renseignez le champ URL LinkedIn.
  4. Cliquez sur Mettre à jour.
Conseil : Assurez-vous que les URLs commencent bien par https://www.linkedin.com/ pour éviter les liens cassés.

2) Shortcode Flux LinkedIn

Le lien vers la page LinkedIn est également utilisé par le shortcode [cne_linkedin_feed] pour diriger les utilisateurs vers votre page entreprise.

Validation attendue

  1. L'icône LinkedIn du footer pointe vers la bonne page entreprise.
  2. Les icônes sur les photos des membres de l'équipe ouvrent bien leurs profils respectifs.
