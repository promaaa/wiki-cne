Gestion de la page Équipe

Les membres sont administrés dans le CPT Équipe.

Champs à compléter pour chaque membre

  • Nom (titre de la fiche)
  • Rôle / description courte (extrait)
  • Photo de profil (image mise en avant)
  • Lien LinkedIn (meta cne_linkedin_url)
  • Pôle (Digital, Environnemental, Ingénierie)

Ordre d'affichage

Le rendu utilise l'ordre WordPress (menu_order puis publication). Utiliser l'ordre natif ou un plugin d'ordering si besoin de classement précis.

Checklist qualité

  • Toutes les photos ont un cadrage homogène.
  • Tous les profils LinkedIn sont valides.
  • Les rôles sont à jour et cohérents avec la communication CNE.

Photo de groupe du mandat

La photo de groupe (photo du mandat) qui apparaît en en-tête de la page Équipe et sur la page d'accueil peut être modifiée directement depuis WordPress.

Comment modifier la photo

  1. Connectez-vous à l'administration WordPress (/wp-admin)
  2. Allez dans Apparence → Personnaliser
  3. Cliquez sur la section "CNE - Équipe"
  4. Cliquez sur "Photo de groupe de l'équipe"
  5. Vous pouvez :
    • Téléverser une nouvelle image depuis votre ordinateur
    • Sélectionner une image déjà présente dans la bibliothèque médias
  6. Cliquez sur "Publier" pour enregistrer

Résultat

La nouvelle image sera automatiquement affichée sur :

  • La page d'accueil (section héro)
  • La page Équipe (/equipe-centrale-nantes-etudes/)

Recommandations

  • Format recommandé : JPG ou PNG
  • Dimensions minimales : 1200px de largeur
  • Ratio recommandé : 16:9 ou 4:3
  • L'image sera recadrée automatiquement pour s'adapter à l'affichage
