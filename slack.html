Connecter votre Slack au site

Votre site internet peut vous prévenir directement sur Slack dès qu'un client vous contacte, demande un devis ou prend rendez-vous ! C'est un excellent moyen de réagir très vite sans avoir à surveiller votre boîte mail.

Pas d'inquiétude : Si vous ne configurez pas Slack (ou si Slack tombe en panne), le site continuera de vous envoyer des e-mails normalement sans afficher la moindre erreur aux clients.

1. Que devez-vous nous fournir ?

Pour que le site puisse "parler" à votre Slack, il a besoin d'une autorisation sous la forme d'un lien spécial, appelé URL Webhook. Ce lien ressemble à ceci :
https://hooks.slack.com/services/T0000/B0000/XXXXXX

Si vous avez déjà ce lien, passez directement à l'étape 3.

2. Comment obtenir ce lien (pour les administrateurs Slack)

  1. Connectez-vous à api.slack.com/apps avec votre compte.
  2. Cliquez sur le bouton vert Create New App puis From scratch.
  3. Donnez-lui un nom (ex: "Site Internet CNE") et choisissez votre espace de travail Slack.
  4. Dans le menu de l'application, cherchez Incoming Webhooks et activez l'option ("On").
  5. Descendez en bas de page et cliquez sur Add New Webhook to Workspace.
  6. Choisissez le canal (ex: #appels-doffres) où le site déposera les alertes.
  7. Copiez le lien Webhook URL généré.

3. Où coller ce lien sur votre site ?

Une fois le lien en votre possession :

  1. Connectez-vous à l'administration de votre site WordPress.
  2. Dans le menu de gauche, allez dans Réglages → CNE Slack.
  3. Collez votre lien dans la case prévue à cet effet et cliquez sur Enregistrer.

4. Faîtes un test !

Sur la même page (Réglages → CNE Slack), vous trouverez un bouton Envoyer un test. Cliquez dessus et vérifiez votre Slack : un message de bienvenue devrait apparaître instantanément !

Sécurité : Votre lien Webhook est comme un mot de passe. Ne le partagez jamais publiquement, sinon n'importe qui pourrait envoyer des messages dans votre Slack.
